# Keep coordination within a zero-spending, small-project scope

The owner sets an exact zero-spending budget and prefers not to operate a separate external
service because that would expand the project. Keep such service operation outside the
default scope and investigate existing capabilities first. This is a scope preference in
addition to the hard budget constraint; a free tier alone does not settle the scope choice.

If no valid shared ownership approval path is reachable, preserve the current connection
and defer new automatic and manual transfers. This deliberately favors protecting the
working Mac over immediate transfer availability. The Away MacBook exception for unknown
home-peer presence does not override this rule. Identify any guarantees that require a
scope change before implementing a weaker substitute.
